To start working, use uv sync to download the necessary libraries needed for the local python evnironment.

To download the kaggle data, must first run in the terminal within the project directory: `mkdir -p ~/.kaggle && echo KGAT_<TOKEN_STRING_GOES_HERE> > ~/.kaggle/access_token && chmod 600 ~/.kaggle/access_token`. Get the full token from the Kaggle user page.
